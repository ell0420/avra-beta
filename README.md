# AVRA Beta

AVRA 소설 집필 앱의 베타 설치 파일을 배포하는 저장소입니다. AVRA 앱 소스 코드는 공개하지 않습니다.

## Windows 0.1.9

**[Windows 64비트 설치 파일 다운로드 — 약 297MB](https://github.com/ell0420/avra-beta/releases/download/v0.1.9-beta.1/AVRA-0.1.9-Windows-x64-setup.exe)**

1. 위 링크에서 설치 파일을 내려받습니다.
2. 다운로드한 `.exe`를 실행해 설치합니다. ZIP 압축 해제는 필요하지 않습니다.
3. 인터넷에 연결된 첫 실행에서 인증에 성공하면 14일 Pro 체험이 자동으로 시작됩니다.

영구 Pro 라이선스는 별도 발급 키로 활성화합니다. 체험이 끝나도 무료 집필 기능과 원고는 유지됩니다.

이 베타에는 소설 모드와 최신 바인더·동기화 수정, 녹음 안정성 및 업데이트 창 개선이 포함됩니다. 논문 모드와 에이전트 모드는 포함하지 않습니다.

## 베타 안내

- Windows x64용입니다.
- 코드 서명이 없어 Windows 보안 경고가 표시될 수 있습니다.
- Windows에서 설치와 기본 실행을 확인했습니다. 글쓰기·녹음·AI 연결의 전체 대화형 검증은 완료하지 않았습니다.
- 파일 무결성 확인용 `SHA256SUMS.txt`는 같은 릴리스에서 받을 수 있습니다.

## 공개 범위

이 저장소는 설치 파일과 사용 안내만 제공합니다. AVRA 자체는 오픈소스로 배포하지 않습니다. 포함된 제3자 구성 요소에는 각 구성 요소의 라이선스가 적용되며, 관련 고지는 설치 패키지에 포함됩니다.

GitHub가 표시하는 `Source code (zip)` / `Source code (tar.gz)`는 이 배포 저장소의 안내문 묶음입니다. 앱을 설치하려면 위의 `.exe`를 받으세요.
