# AVRA Beta

AVRA 소설 집필 앱의 베타 설치 파일을 배포하는 저장소입니다. AVRA 앱 소스 코드는 공개하지 않습니다.

## 0.1.9 다운로드

- **[Windows 64비트 설치 파일](https://github.com/ell0420/avra-beta/releases/download/v0.1.9-beta.1/AVRA-0.1.9-Windows-x64-setup.exe)** — 내려받은 `.exe`를 실행하세요.
- **[Mac Apple Silicon 설치 파일](https://github.com/ell0420/avra-beta/releases/download/v0.1.9-beta.1/AVRA-0.1.9-macOS-Apple-Silicon.dmg)** — macOS 26 이상, M1·M2·M3 등 Apple Silicon용입니다. `.dmg`를 열어 AVRA를 응용 프로그램 폴더로 옮기세요.

Mac 버전은 Apple 공증을 받지 않은 베타입니다. 출처를 확인한 뒤 처음 실행할 때 차단되면 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**에서 허용할 수 있습니다. 자세한 내용은 [Apple의 안내](https://support.apple.com/ko-kr/102445)를 참고하세요. Windows에서는 코드 서명이 없어 보안 경고가 표시될 수 있습니다.

인터넷에 연결된 첫 실행에서 인증에 성공하면 14일 Pro 체험이 자동으로 시작됩니다. 영구 Pro 라이선스는 별도 발급 키로 활성화합니다. 체험이 끝나도 무료 집필 기능과 원고는 유지됩니다.

이 베타는 소설 모드와 최신 바인더·동기화 수정, 녹음 안정성 및 업데이트 창 개선을 포함합니다. 논문 모드와 에이전트 모드는 포함하지 않습니다.

## 확인 사항

- Windows에서 설치와 기본 실행을 확인했습니다.
- Mac 패키지의 빌드 및 서명과 디스크 이미지 무결성을 확인했습니다. 다른 실제 Mac에서의 설치·실행은 확인하지 않았습니다.
- 두 플랫폼 모두 글쓰기·녹음·AI 연결의 전체 대화형 검증은 완료하지 않았습니다.
- 릴리스에 있는 `SHA256SUMS.txt`와 `SHA256SUMS-macOS.txt`는 각 설치 파일의 무결성 확인용입니다.

## 공개 범위

이 저장소는 설치 파일과 사용 안내만 제공합니다. AVRA 자체는 오픈소스로 배포하지 않습니다. 포함된 제3자 구성 요소에는 각 구성 요소의 라이선스가 적용됩니다.

GitHub가 표시하는 `Source code (zip)` / `Source code (tar.gz)`는 이 배포 저장소의 안내문 묶음입니다. 앱을 설치하려면 위의 설치 파일을 받으세요.
