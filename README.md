# AVRA Beta

AVRA 소설 집필 앱의 베타 설치 파일과 사용 안내를 배포합니다. 앱 소스 코드는 비공개입니다.

## 다운로드

- **[Windows 0.1.24 — 64비트 설치 파일](https://github.com/ell0420/avra-beta/releases/download/v0.1.24-beta.1/AVRA-0.1.24-Windows-x64-setup.exe)**: 내려받은 `.exe`를 실행하세요.
- **[Mac 0.1.24 — Apple Silicon 설치 파일](https://github.com/ell0420/avra-beta/releases/download/v0.1.24-beta.1/AVRA-0.1.24-macOS-Apple-Silicon.dmg)**: macOS 26 이상, M1 이후 Apple Silicon용입니다. `.dmg`를 열어 AVRA를 응용 프로그램 폴더로 옮기세요.

0.1.24은 오픈베타 버전입니다. 2027년 2월 10일까지 키 없이 모든 Pro 기능을 쓸 수 있습니다. 새 원고를 만들 때 자동 요약이 반복되던 랙을 고쳤고, 가이드 탭에서 자동 요약 대상을 고르고, 녹음 전 문체 자료를 준비할 수 있습니다. 이미 설치한 앱은 **도움말 > 앱 업데이트**에서 0.1.24로 업데이트됩니다(Mac·Windows 공통). '설치 준비가 끝났습니다'가 나올 때까지 기다린 뒤 **지금 설치**를 누르세요. 업데이트가 실패하면 위 설치 파일로 설치하세요. 원고와 설정은 그대로 유지됩니다.

오픈베타 기간에는 체험 없이 모든 Pro 기능을 쓸 수 있습니다. 베타가 끝나면 인터넷에 연결된 첫 실행에서 14일 Pro 체험이 시작되고, 영구 Pro는 별도 발급 키로 활성화합니다. 체험이 끝나도 무료 집필 기능과 원고는 유지됩니다.

소설 모드와 최신 바인더·동기화, 녹음 안정성 및 업데이트 창 개선을 포함합니다. 논문·에이전트 모드는 포함하지 않습니다.

## Mac에서 열리지 않을 때

AVRA Mac 베타는 아직 Apple 공증을 받지 않았습니다. 처음 열 때 "Apple은 'AVRA Desktop'에 악성 코드가 없음을 확인할 수 없습니다"라는 창이 뜨면 **휴지통으로 이동을 누르지 말고** 아래 순서로 여세요. 처음 한 번만 하면 됩니다.

1. `.dmg`를 열고 AVRA를 **응용 프로그램** 폴더로 옮깁니다(DMG 창 안에서 바로 실행하지 마세요).
2. 응용 프로그램 폴더의 AVRA를 더블클릭하고, 경고 창에서 **완료**를 누릅니다.
3. 바로 **시스템 설정 > 개인정보 보호 및 보안**을 열고 맨 아래 **보안** 칸에서 AVRA 옆의 **그래도 열기**를 누른 뒤 암호를 입력합니다.
4. 다시 뜨는 창에서 **열기**를 누릅니다.

**그래도 열기**가 보이지 않으면 2번을 다시 한 뒤 곧바로 설정을 여세요. 이 버튼은 방금 막힌 앱에 대해서만 잠시 표시됩니다.

## 베타 안내

Windows는 코드 서명이 없어 보안 경고가 표시될 수 있습니다. Mac은 Apple 공증을 받지 않은 베타입니다. 출처를 확인한 뒤 실행이 차단되면 [Apple 안내](https://support.apple.com/ko-kr/102445)에 따라 시스템 설정의 개인정보 보호 및 보안에서 허용할 수 있습니다.

Windows 0.1.24은 Windows 빌드 서버에서 설치·기본 실행과 공개 0.1.23 위에 덮어 업데이트되는 것을 확인했습니다. 0.1.20부터 Windows AI 질문은 빌드 서버의 AI 질문·MCP 연결 부품 시험과 실제 Windows PC의 ChatGPT 질문으로 확인했습니다. Mac은 패키지 빌드·서명·내장 검색 라이브러리·디스크 이미지 무결성을 확인했고, 0.1.15는 새 사용자 계정에서 GitHub로 받은 앱의 AI 연결·원고 세팅을, 0.1.17은 같은 계정에서 0.1.15→0.1.17 앱 안 업데이트를 확인했습니다. 다른 실제 Mac에서는 설치·실행하지 않았습니다.

각 릴리스의 `SHA256SUMS` 파일로 설치 파일 무결성을 확인할 수 있습니다. 포함된 제3자 구성 요소에는 각각의 라이선스가 적용됩니다.

GitHub의 자동 `Source code (zip)` / `Source code (tar.gz)`는 이 배포 저장소의 안내문 묶음입니다. 앱 설치에는 위의 `.exe` 또는 `.dmg`를 사용하세요.
